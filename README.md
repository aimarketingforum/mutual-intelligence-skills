# Mutual Intelligence Skills Library

A growing collection of Claude Skills built on the Mutual Intelligence™ framework by Jason and Isaiah Cormier, co-founders of [Mutual Intelligence](https://mutualintelligence.ai) and the AI Marketing Forum (join the commmunity at https://skool.com/aimarketing).

## What Are Skills?

Skills are system prompts for Claude Projects that give Claude specialized capabilities aligned to a specific workflow or process. Each skill in this library is part of the Mutual Intelligence **Clarify → Build → Deploy** action cycle.

## How to Install a Skill

1. Download the `SKILL.md` file from the skill folder you want
2. Upload the SKILL.md file at the start of a new Claude chat (recommended), or paste the contents of the skill if you prefer
3. Start using it
